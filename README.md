Orbital Drift — a slingshot puzzle in deep space. Drag back from the ship to aim, release to launch; gravity bends your probe around planets, mines, suns and black holes. Collect every star shard, then slip through the gate. 12 hand-designed levels, 3 launches each, stars for skill — every level was machine-checked solvable before it shipped.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
